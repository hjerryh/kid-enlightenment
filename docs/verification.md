## 声音更新验证（2026-10-26）

- 已将全部 854 条发布录音换成神经网络女声：英文 Jenny（语速 -10%）、普通话 Xiaoxiao（-8%），自然音高，继续使用本地 MP3 和离线缓存。

- `npm run build`：成功；当前离线清单 993 个文件、26.72 MiB，缓存版本 `little-world-443f1522610dd9335246`。
- `npx playwright test tests/e2e/language.spec.ts tests/e2e/offline.spec.ts`：10/10 通过，Chrome 与 WebKit 各 5 项。验证语言切换、实际音频播放、进度保留、手机布局，以及全量新音频缓存和断网播放。

## 范围说明

完成的是响应式网页 PWA，可部署到 HTTPS 静态托管。没有发布公网或应用商店，没有原生安装包、云账号或跨设备同步。

移动视口、触摸模拟与 WebKit 引擎验证，不等于在实体 iPad 或 iPhone 上完成测试。局域网 HTTP 可体验学习功能；离线缓存需生产构建在 HTTPS 或 localhost 下首次在线访问完成。

进度只保存在当前设备浏览器中；禁止保存时会提示用户。发现与答对分别统计，不把答对一次描述为完全掌握。
