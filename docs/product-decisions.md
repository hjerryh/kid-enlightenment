# 当前产品决定

## 用户明确的信息

- 产品目标：儿童认知启蒙 App。
- 年龄：3–8 岁。
- 语言：最初要求英文，后续明确要求支持中英文切换。
- 设备：iPad 和手机。
- 初期指示：“一切都按你推荐的”，未明确的实现细节交由实现者决定。
- 后续扩充要求：数字换成所提供参考图的样式；动物包含十二生肖，并在生肖以外再扩充 50 种。
- 声音反馈（2026-10-26）：“声音不好听”，需要改善听感。

## 初版实现选择（历史记录）

以下保留初版范围与素材决策；当前内容数量及数字样式以文末的扩充记录为准。

- React、TypeScript、Vite 的响应式 PWA；首先交付可运行网页，不生成原生 App Store 包。
- iPad 与 iPhone 通过 Safari 使用，Android 手机通过现代浏览器使用；部署到 HTTPS 后可添加到主屏幕。离线使用需先联网完成生产版缓存，开发模式不安装离线缓存。
- 采用六个主题、36 个准确可视的概念构成完整的初版学习内容。
- 全部学习阶段开放六个主题；同主题按阶段调整题干与选择数量，默认 5–6 岁，家长可改为 3–4 或 7–8 岁。
- 儿童主要通过图、声音和点按独立探索，家长提供初始设置与适量陪伴。
- 图卡、听音找图、配对、错题回顾和发现记录形成学习闭环。
- 初版不需要账号和服务器；进度只存本机浏览器，跨设备同步需未来明确提出再加。
- 首次每日目标为六个不同概念，完成后建议休息；不使用倒计时、惩罚或排名。
- 采用 36 张原创柔和绘本图卡与狐狸角色 Pip、主题场景，共 38 张插画；英文词和题干使用随应用提供的 147 条录音（36 条概念词音频、108 条题干、3 条提示）。
- 不沿用参考图错误分类；数字强调实际数量，词语练习避免同词跨主题歧义。

以上为用户授权下的实现选择，不表示用户逐项指定了技术栈、默认年龄或功能细节。

## 中英文切换（2026-10-22）

- 用户明确要求：支持中英文切换。
- 实现选择：简体中文、普通话与美式英文；右上角直接切换，也可在家长专区设置。界面、词卡、题干、配对、朗读一起切换。
- 默认保留原来的英文；选择单独存储，刷新或重新打开后恢复。两种语言共用同一套认知进度，不把切换语言算成新的发现或单独的语言掌握程度。
- 中文补充 147 条本地音频，和英文共 294 条；首次联网完成缓存后，两种语言均支持离线使用。
- 继续使用当前响应式网页 PWA，本次是语言功能更新。

## 数字样式与动物内容扩充（2026-10-22）

- 用户明确要求：数字参照所提供图片的风格；动物增加十二生肖，并在生肖以外再扩充 50 种。
- 数字实现选择：使用原创毛绒立体数字图，覆盖 0–19，共 20 张。每张卡片显示数字图、当前语言名称与阿拉伯数字；平板四列、手机两列，支持直接输入数值搜索。3–4 岁识别数字，5–6 岁巩固名称与字形的对应，7–8 岁练习简单加减法。新的数字图与题干替代初版圆点计数方案。
- 动物实现选择：共 62 个条目，包含鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪，以及 50 种其他动物。龙作为生肖文化中的传说形象呈现，名称卡明确标注“传说中的动物”，相关题干不把它说成现实动物。
- 为方便儿童分批探索，采用十二生肖（12）、陆地动物（23）、鸟类朋友（10）、水中动物（9）、更多动物朋友（8）五个学习分组。它们是内容浏览集合，不作为生物学分类教材。选定分组后，图卡前后切换、听音找图、配对和错题回顾均保留该分组。
- 六个主题保留，水果、颜色、形状、日常世界仍各六个条目；当前合计 106 个概念。首页、发现统计和完成徽章使用实际内容总数，继续识别已有概念 ID，因此不清除原有学习进度。
- 两种语言完整覆盖扩充内容：英文和普通话各 427 条录音（106 个名称、318 个分龄题干、3 条提示），合计 854 条，沿用本地播放与生产版首次缓存后的离线使用方式。
- 素材实现选择：新增动物通过 Python 标准库生成原创 SVG；数字通过 Nunito 字体轮廓和本地纹理、光影绘制生成 WebP，依赖 Pillow、NumPy、SciPy、fontTools 与 Brotli。参考照片提供样式方向，不直接使用其中的图片。
- 本次继续扩充当前响应式网页 PWA，未改变设备支持方式、账号策略或发布形式。最终验证结果单独记录于 `docs/verification.md`，本决策记录不代替验收。

## 中英文声音更新（2026-10-26）

- 用户明确反馈：当前声音不好听。具体声线、语速和处理方式由实现者按适合儿童启蒙的方向选择，不视为用户逐项指定。
- 默认生成方案改为神经网络女声：美式英文 `en-US-JennyNeural`，普通话 `zh-CN-XiaoxiaoNeural`，用于替代此前的 macOS Samantha／Tingting 录音。英文相对默认语速放慢 10%，中文放慢 8%；保留自然音高，以更自然、柔和的朗读为目标。
- 统一处理首尾静音和响度，保留句内停顿；响度目标 -18 LUFS、真峰值上限 -2 dBTP，输出 24 kHz、96 kbps、单声道 MP3。每条录音需在 0.2–12 秒内，为现有播放器的 15 秒时限保留加载余量。
- 覆盖范围仍为 854 条（每种语言 427 条），包括全部词语、分龄题干和鼓励提示。内容、概念 ID、语言切换与学习进度保持兼容。
- 生成工具默认使用固定版本 `edge-tts==7.3.1`。维护生成时联网，把公开课程文案发送给 Edge 语音服务；运行中的儿童 App 播放随应用提供的本地文件，不调用该服务，首次缓存后继续离线使用。
- 生成前先暂存并检查整套语言素材；网络请求或音频检查失败时不发布该套更新。配置指纹覆盖引擎、声线、语速和处理参数，文案与文件哈希参与复用判断，避免换声后误用旧素材。有效暂存文件可供下次继续生成。
- macOS `say` 保留为显式选择的维护后备引擎，通过 `--engine macos` 启用，不在神经语音生成失败时自动混入旧系统声线。客户端遇到本地录音播放失败时，仍保留设备语音兜底。
- 本条记录描述更新方案，不代表对全部新录音完成试听或验证；最终生成、文件与浏览器检查结果以 `docs/verification.md` 为准。
